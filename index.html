cgcut

CG 리스트 → 샷 자르기

CG 리스트 엑셀을 넣으면 컷 목록과 TC를 확인하고, 원본 영상에서 해당 샷만 잘라내는 실행 파일(.bat)을 만들어 드립니다. 영상은 내 PC에서 처리되어 용량 제한이 없습니다.

1CG 리스트 엑셀
엑셀 파일을 끌어다 놓거나 클릭해서 선택 .xlsx — 파일은 서버로 올라가지 않고 이 브라우저 안에서만 읽습니다.
2원본 영상 (선택 — 회차 매칭 미리 확인용, 업로드되지 않음)
파일명에 EP04, 4화, 제4회가 있으면 시트와 자동으로 짝지어집니다. 영상이 1개면 모든 컷에 씁니다.
    3옵션
    자르는 방식
    처리할 시트
    4실행 파일 받기
    1. 받은 .bat 파일을 엑셀과 원본 영상이 있는 폴더에 넣고 더블클릭하세요. (영상은 하위 폴더에 있어도 됩니다)
    2. 결과는 같은 폴더의 cgcut_out에 생기고, 끝나면 폴더가 자동으로 열립니다. 샷별 IN·OUT은 cgcut_report.csv에 정리됩니다.
    3. 처음 한 번만: 파이썬 설치(첫 화면 Add python.exe to PATH 체크) + 명령 프롬프트에서 winget install Gyan.FFmpeg
    4. 브라우저가 ".bat 파일은 위험할 수 있음"이라고 하면 유지를 누르세요. 윈도우가 "PC 보호" 창을 띄우면 추가 정보 → 실행.
