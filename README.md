# cgcut

CG 리스트 엑셀(.xlsx)에 적힌 **TC(타임코드)** 를 읽어서, 원본 영상에서 그 샷만 잘라내는 도구입니다.

- TC가 가리키는 샷을 **장면 전환을 찾아 컷 단위로 통째로** 잘라냅니다 (프레임 단위로 정확).
- `01:36:10:07 ~ 01:36:20:03` 처럼 IN~OUT이 적혀 있으면 그 구간을 그대로 자릅니다.
- 잘린 파일에는 원본 타임코드가 그대로 들어가서, 편집·CG 툴에서 원래 위치를 그대로 알 수 있습니다.
- 회차별 영상이 여러 개면 파일명의 `EP04`, `4화`, `제4회` 등을 보고 시트(EP04)와 자동으로 짝지어 줍니다.
- TC 없이 **Scan Name(클립명, 예: `A027 C023`)** 만 있는 리스트는, 카메라 원본 폴더에서 해당 클립 파일을 찾아 모아 줍니다.

```
EP04 시트 no.3, TC 01:04:30:03  →  cgcut_out/EP04_3_01-04-29-12.mov  (그 샷 전체, TC 01:04:29:12부터)
```

---

## 설치 없이 쓰기: cgcut.exe (윈도우)

[Releases](https://github.com/Josingp/cgcut/releases/latest)에서 `cgcut.exe` **하나만 받아서 실행**하면 됩니다. ffmpeg가 안에 들어 있어서 따로 설치할 것이 없습니다.
처음 실행할 때 윈도우가 "Windows의 PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. (서명이 없는 파일이라 뜨는 안내이며, 바이러스가 아닙니다.)

#### 하는 일
CG 리스트(엑셀·PDF)에 적힌 TC, 또는 직접 입력한 TC를 읽어서, 원본 영상에서 **그 TC가 들어 있는 샷을 통째로** 프레임 단위로 정확하게 잘라 저장합니다. 잘린 파일에는 원본 타임코드가 그대로 들어가 있어서 편집·CG 툴에서 원래 위치를 바로 알 수 있습니다.

#### 사용 순서
1. **원본 영상** — `영상 파일…`로 파일을 고르거나, `폴더…`로 회차별 영상이 모여 있는 폴더를 고릅니다.
   영상이 여러 개면 파일명의 `EP04`, `4화`, `제4회` 같은 표기를 보고 리스트의 회차와 자동으로 짝지어 줍니다. 영상이 1개면 모든 TC를 그 영상에서 찾습니다.
   한 편을 `영화_1부.mov`, `영화_2부.mov`, `영화_3부.mov`처럼 부(part)로 나눠 내보낸 경우는 **이어진 한 편으로 인식**합니다. 각 부의 내장 TC(없으면 앞 부에 바로 이어진다고 보고)를 기준으로, 리스트 TC가 어느 부에 들어가는지 찾아 그 파일에서 자릅니다. `part2`, `pt.2`, `_02` 같은 표기도 됩니다. 부 파일들의 TC가 서로 겹치면(각 부가 01:00:00:00부터 따로 시작) 별개 영상으로 봅니다.
2. **자를 TC** — 둘 중 하나(둘 다도 가능)
   - `xlsx / pdf / edl…`로 CG 리스트 파일 선택. 헤더에 `TC`(또는 `Timecode`, `타임코드`) 열이 있으면 자동으로 찾고, 시트 이름이 `EP04`면 그 시트의 컷은 4화 영상에서 자릅니다. 한 칸에 `01:36:10:07 ~ 01:36:20:03`처럼 적혀 있으면 그 구간을 그대로 자릅니다.
   - 직접 입력 칸에 한 줄에 하나씩:
     - `01:04:24:08` → 이 TC가 들어 있는 샷 전체
     - `01:36:10:07 ~ 01:36:20:03` → 이 구간만 (끝 TC는 마지막 프레임 포함)
     - `창문리무브 01:04:24:08` → 앞에 쓴 이름이 파일명에 들어감
     - `EP04` 한 줄을 넣으면 그 아래 TC들은 EP04 영상에서 자름
   - **EDL(CMX3600)** 도 됩니다. 프리미어/다빈치/아비드에서 CG 컷만 모은 시퀀스를 EDL로 내보내면, 각 이벤트의 레코드(타임라인) IN~OUT을 그대로 자릅니다. `* FROM CLIP NAME:` 줄이 있으면 그 이름이 파일명에 들어갑니다. 컷마다 소스 TC로 자르고 싶으면 "EDL은 소스 TC 사용" 체크(명령줄은 `--edl-source`).
3. **옵션**
   - 저장 폴더 — 비워 두면 영상 옆에 `cgcut_out` 폴더가 생깁니다.
   - 파일명 앞머리 — 기본값은 영상 파일명 앞부분. 예: `쩔해주세요` → `쩔해주세요_EP04_3_01-04-29-12.mov`
   - 형식 — **ProRes 422 HQ(.mov)** 가 기본(CG 작업용). 확인용이면 H.264(.mp4), 플레이트가 이미지로 필요하면 PNG 시퀀스.
   - 자르는 방식 — **샷 전체**는 TC 앞뒤의 장면 전환(컷)을 자동으로 찾아 그 샷을 통째로 자릅니다. **TC 기준 고정 길이**는 전환을 찾지 않고 TC 앞 n초·뒤 n초를 자릅니다.
   - 핸들 — 샷 앞뒤에 여유 프레임을 더 붙입니다(예: 12).
   - 영상 첫 프레임 TC — 보통 비워 둡니다(영상 파일에 든 TC를 씁니다). 파일에 TC가 없으면 리스트 TC가 01시대일 때 `01:00:00:00` 시작으로 가정하고, 그래도 안 맞으면 여기에 직접 적습니다.
4. **▶ 자르기** — 진행 상황 창에 전체 진행률(완료 컷 수)과 지금 하는 작업(장면 검출 / 자르기)의 프레임 단위 진행률·경과 시간·남은 시간이 0.25초마다 갱신됩니다. 큰 파일은 처음 장면 검출에 시간이 걸리니 이 표시를 보고 기다리면 됩니다. 끝나면 저장 폴더가 열립니다. 중간에 `중단`을 누르면 지금 컷까지만 하고 멈춥니다. 다시 실행하면 이미 만든 파일은 건너뛰고 나머지만 만듭니다.

#### 결과물
- `앞머리_EP04_3_01-04-29-12.mov` — `회차_리스트번호_실제 시작TC`
- `cgcut_report.csv` — 컷마다 리스트 TC / 실제로 자른 IN·OUT TC / 길이 / 상태 / 비고. 엑셀로 열립니다.
  - **건너뜀**: TC가 영상 범위 밖(다른 회차 영상이거나 TC 오타)이거나 TC가 없는 행
  - 비고에 "전환 못 찾음"이 있으면 장면 전환을 못 찾아 최대 30초로 잘린 것이니 그 컷만 확인하세요. 디졸브·어두운 장면에서 생길 수 있습니다.

#### 자주 막히는 것
- **잘린 위치가 몇 초씩 어긋남** → 영상에 든 시작 TC와 리스트 TC 기준이 다른 경우입니다. "영상 첫 프레임 TC"에 편집 시퀀스 시작 TC(보통 `01:00:00:00`)를 적어 보세요.
- **"TC가 영상 범위 밖"** → 리스트 TC의 시(時)가 다른 컷과 다르면 대부분 오타입니다. 다른 회차 영상을 넣은 경우도 같은 메시지가 납니다.
- **리스트에 TC가 없고 클립명(Scan Name)만 있음** → 이 프로그램은 TC로 자르는 용도입니다. 카메라 원본 폴더에서 클립을 모으는 기능은 명령줄(`cgcut.exe 리스트.xlsx --clips-dir 폴더 -o 저장폴더`)로만 됩니다.
- 매우 긴 영상(1시간 이상)은 장면 검출에 몇 분 걸립니다. 한 번 검출하면 저장 폴더에 캐시가 남아 다음부터는 바로 됩니다.


## 웹에서 쓰기 (Vercel 페이지)

배포된 페이지에 CG 리스트 엑셀을 끌어다 놓으면

1. 컷 목록과 TC를 표로 보여 주고, **TC 오타(다른 컷과 시가 다름)·중복 TC·프레임 범위 초과**를 표시합니다.
2. 원본 영상 파일을 선택하면(업로드되지 않음, 파일명만 사용) 어느 회차가 어느 영상과 짝지어지는지 미리 보여 줍니다.
3. 옵션을 고르고 **실행 파일(.bat)** 을 받습니다. 이 .bat을 엑셀·영상이 있는 폴더에 넣고 더블클릭하면 PC에서 잘라 `cgcut_out` 폴더에 저장합니다.
   (실행할 때마다 최신 `cgcut.py`를 자동으로 받아 옵니다.)

엑셀·영상 모두 서버로 올라가지 않습니다. 영상 처리는 PC의 ffmpeg로 하기 때문에 원본 용량 제한이 없습니다.

## 설치 (윈도우, 한 번만)

1. **파이썬** — https://www.python.org/downloads/ 에서 설치. 설치 첫 화면에서 **"Add python.exe to PATH" 체크**.
2. **ffmpeg** — 시작 메뉴에서 "명령 프롬프트"를 열고 아래 한 줄 실행 후, 창을 닫았다 다시 엽니다.
   ```
   winget install Gyan.FFmpeg
   ```
3. **이 도구 받기** — 이 저장소 페이지에서 `Code` → `Download ZIP` → 압축 풀기.

(맥: `brew install ffmpeg python` 후 `pip3 install openpyxl`)

## 가장 쉬운 사용법: 끌어다 놓기

압축 푼 폴더의 **`cgcut_drag.bat`** 위에

- CG 리스트 엑셀 1개 + 원본 영상 파일(여러 개 가능)
- 또는 CG 리스트 엑셀 1개 + 회차별 영상이 들어 있는 폴더

를 **한꺼번에 선택해서 끌어다 놓으면** 됩니다. 결과는 엑셀 파일 옆 `cgcut_out` 폴더에 생깁니다.
처음 실행할 때 필요한 부품(openpyxl)을 자동으로 설치합니다.

## 명령어로 쓰기 (옵션 조정할 때)

```
python cgcut.py CG리스트.xlsx --video 편집본.mov -o out
python cgcut.py CG리스트.xlsx --video-dir D:\편집본\ -o out --handles 12
python cgcut.py CG리스트.xlsx --video 편집본.mov --dry-run          # 자르지 않고 계획만 확인
python cgcut.py CG리스트.xlsx --clips-dir E:\카메라원본\ -o out       # 클립명으로 원본 모으기
```

| 옵션 | 설명 | 기본 |
|---|---|---|
| `--video 파일` | 원본 영상 (여러 번 지정 가능) | |
| `--video-dir 폴더` | 회차별 영상 폴더 — 파일명의 `EP04`/`4화` 등으로 시트와 매칭 | |
| `-o 폴더` | 출력 폴더 | `cgcut_out` |
| `--codec` | `prores`(ProRes 422 HQ .mov) / `prores422` / `h264`(.mp4) / `png`(이미지 시퀀스) / `copy`(재인코딩 없음 — 키프레임 단위라 앞뒤가 몇 프레임 어긋날 수 있음) | `prores` |
| `--handles N` | 샷 앞뒤로 N프레임 여유(핸들) 추가 | `0` |
| `--mode fixed` | 장면 전환을 찾지 않고 TC 기준 고정 길이로 자름 (`--before 1 --after 5` 초) | `shot` |
| `--start-tc` | 영상 첫 프레임의 TC를 직접 지정 (예: `01:00:00:00`) | 파일 내장 TC |
| `--scene-threshold` | 장면 전환 감도 (0~1, 낮을수록 민감). 디졸브·어두운 장면에서 컷을 못 찾으면 `0.2`, 너무 잘게 쪼개지면 `0.5` | `0.35` |
| `--max-before/--max-after` | 장면 전환을 못 찾을 때 TC 앞뒤 최대 몇 초까지 자를지 | `30` |
| `--snap N` | TC가 다음 샷 시작 N프레임 앞이면 다음 샷으로 간주 (리스트 TC가 1~2프레임 이른 경우 보정) | `2` |
| `--sheet EP04` | 특정 시트만 처리 (여러 번 지정 가능) | 전체 |
| `--no-audio` | 오디오 빼기 | |
| `--overwrite` | 이미 만든 파일도 다시 만들기 (기본은 건너뜀 → 중간에 끊겨도 이어서 실행 가능) | |

## 결과물

- `EP04_3_01-04-29-12.mov` — `회차_번호_실제IN타임코드`
- `cgcut_report.csv` — 샷마다 리스트 TC / 실제로 자른 IN·OUT TC / 길이 / 상태 / 비고. 엑셀로 열립니다.
  - **건너뜀**: TC가 영상 범위 밖이거나(다른 회차 영상이거나 TC 오타), TC가 없는 행
  - 비고에 "전환 못 찾음"이 있으면 최대 길이로 잘린 것이니 한 번 확인하세요.

## 리스트 양식

헤더 행에서 아래 이름의 열을 자동으로 찾습니다 (대소문자·줄바꿈 무시).

- TC: `TC`, `Timecode`, `TC IN`, `타임코드` … / OUT은 `TC OUT`, `OUT` 열이나 같은 칸의 두 번째 TC
- 번호: `no.`, `No`, `번호` · 회차: `EP`, `회차` (없으면 시트 이름의 `EP04` 사용)
- 클립명: `Scan Name`, `Clip`, `클립명`, `Reel` …
- 헤더가 없으면 `00:00:00:00` 모양의 값이 가장 많은 열을 TC로 씁니다.

TC 표기는 `01:04:24:08`, `01:04:24;08`(드롭프레임), `01:04:24.08` 모두 인식합니다.

## 영상 TC 맞추기

- 영상 파일에 타임코드가 들어 있으면(프리미어/다빈치에서 내보낸 mov·mxf 대부분) 그걸 기준으로 씁니다.
- 없으면, 리스트 TC가 01시간대이고 영상 길이를 넘을 때 `01:00:00:00` 시작으로 가정합니다. 다르면 `--start-tc`로 지정하세요.
- 리스트 TC가 편집본(시퀀스) 기준이어야 합니다. 카메라 원본 TC를 적은 리스트라면 `--clips-dir` 방식을 쓰세요.
